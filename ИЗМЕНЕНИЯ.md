# Что улучшено в SYNC

## Пользовательский интерфейс
- Навигация и ключевые действия доступны на мобильных экранах.
- Чат и приглашения становятся активны только после подключения комнаты — меньше неудачных отправок и копирования пустой ссылки.
- Добавлены состояния создания комнаты и поиска, а также защита от повторных кликов и устаревших результатов.
- Модальные окна блокируют прокрутку фона, поддерживают `Escape`, удерживают клавиатурный фокус и возвращают его к элементу, который открыл окно.
- Улучшены фокусные состояния, адаптация полей ввода на телефонах и поведение при уменьшенном движении.

## Надёжность
- Исправлены гонки при смене видео и асинхронной загрузке результатов; позиция предыдущего RUTUBE-видео не переносится на новое.
- При ошибке отправки сообщения оптимистичное сообщение удаляется, а текст черновика остаётся в поле ввода.
- Повторно загружается API YouTube после ошибки загрузки скрипта.
- Добавлен fallback копирования ссылки для браузеров без Clipboard API.

## PWA и поиск
- Service Worker регистрируется приложением, обновляет сетевые ресурсы и хранит оболочку для офлайн-открытия.
- Добавлен обработчик установки PWA, если браузер поддерживает приглашение к установке.
- Добавлен отсутствовавший в исходном архиве исходник Edge Function `supabase/functions/sync-search/index.ts`.

## Что нужно сделать при публикации
1. Загрузить файлы сайта в корень GitHub Pages (папку `supabase/` можно не копировать на хостинг сайта).
2. Развернуть `sync-search` в Supabase и добавить `YOUTUBE_API_KEY` в Edge Function Secrets, если нужен поиск YouTube. Проверку JWT оставить включённой.
3. Существующая база данных не менялась: новых SQL-миграций для этих улучшений не требуется.

## Проверки
- `node --check app.js` и `node --check sw.js`.
- Проверка HTML на дублирующиеся `id`, валидности JSON-манифеста и синтаксиса CSS.
- Проверка TypeScript Edge Function с Deno API stub и DOM-типами.

Проверки не заменяют тест входа, Realtime и WebRTC в живом проекте Supabase: для них нужны URL, ключи, OAuth-настройки и несколько реальных клиентских устройств.
