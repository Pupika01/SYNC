Остался один технический шаг: добавь URL проекта Supabase и публичный anon key в config.js, затем обнови страницу.

  1. Supabase → Project Settings → API.
  2. Скопируй Project URL.
  3. Скопируй ключ anon / publishable, не service_role.

После этого здесь появится вход и регистрация. Не отправляй никому секретные ключи.
