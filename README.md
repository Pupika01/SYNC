# SYNC 0.4 — watch together

Обновлённый PWA/сайт для совместного просмотра: минималистичный тёмный интерфейс с фиолетовыми акцентами, комнаты по приватной ссылке, друзья, чат, вход по Google, аватар и встроенные плееры YouTube/RUTUBE.

## Что изменилось

- Главный экран без поисковой строки: крупное «Что будем смотреть?» и карточки площадок.
- Нажатие на площадку открывает её панель внутри SYNC, а не переводит на новый сайт.
- YouTube: встроенный плеер через YouTube IFrame Player API; поиск внутри SYNC требует ключ YouTube Data API v3.
- RUTUBE: встроенный официальный embed-плеер с синхронизацией play/pause/seek через `postMessage`; встроенный поиск использует публичный endpoint RUTUBE, который не является стабильным публичным контрактом и может ограничивать запросы с других сайтов.
- Выбор видео отправляется участникам комнаты через Supabase Realtime; текущий выбранный ролик и позиция сохраняются в `sync_room_state`, поэтому новый участник может увидеть тот же контент.
- Play/Pause и позиция синхронизируются; сервер комнаты периодически корректирует отставание участников.
- На некоторых браузерах автозапуск со звуком блокируется политикой браузера. Тогда участнику нужно один раз нажать «Начать общий просмотр».
- Google OAuth и загрузка аватара в Supabase Storage.
- Фирменная SVG-иконка SYNC и `manifest.webmanifest`.

## Важно о платформах

Обычная веб-страница не может надёжно показывать внутри iframe любой внешний сайт и читать действия пользователя внутри него: это ограничивается `X-Frame-Options` и `Content-Security-Policy`. Поэтому SYNC открывает внутри себя поиск/подборку только там, где можно использовать официальный встроенный плеер.

- **YouTube** — встроенный плеер и API управления поддерживаются.
- **RUTUBE** — официальный embed-плеер и API управления через `postMessage` поддерживаются для разрешённых к встраиванию роликов. Само видео должно быть доступно для embed.
- **VK Видео** — карточка отображается, но интеграция каталога и управления плеером ещё не подключена.
- **Netflix и Кинопоиск** — защищённый просмотр нельзя просто встроить в сторонний сайт. В текущей версии их кнопки показывают пояснение внутри SYNC и не делают неожиданный переход.

SYNC не обходит DRM, платную подписку или правила платформ.

## 1. Настрой Supabase schema

Ты уже запускал `supabase.sql` для версии 0.3. Для обновления НЕ запускай его повторно. Открой Supabase → SQL Editor → New query, скопируй весь файл `supabase-migration-04.sql` и нажми Run.

Миграция:
- добавит `avatar_url` в `sync_profiles`;
- создаст `sync_room_state` и RLS-политики для доступа только участников комнаты;
- создаст публичный bucket `sync-avatars` с ограничением 5 МБ и правами загрузки только в собственную папку пользователя;
- обновит профильный trigger, чтобы при Google OAuth сохранять имя и аватар из metadata провайдера.

## 2. Google вход

В Supabase:
1. Authentication → Sign In / Providers → Google → Enable.
2. В Google Cloud Console создай OAuth Client ID типа Web application.
3. В Authorized redirect URIs добавь callback, который Supabase показывает в окне Google Provider. Обычно он имеет вид `https://<project-ref>.supabase.co/auth/v1/callback`.
4. Вставь Client ID и Client Secret в настройки Google Provider в Supabase. Секрет хранится только в Supabase, не в `config.js`.
5. Authentication → URL Configuration: Site URL — адрес GitHub Pages; в Redirect URLs добавь точный адрес сайта, включая путь `/sync-watch/`.

Кнопка «Продолжить с Google» уже реализована в приложении. Пока Google Provider не включён, Supabase вернёт ошибку провайдера.

## 3. Настрой config.js

В архиве `config.js` уже заполнены Supabase URL и Publishable Key из текущего проекта. Никогда не вставляй в этот файл `service_role` или secret key.

Для поиска YouTube добавь `YOUTUBE_API_KEY`:
1. Google Cloud Console → APIs & Services → Library → YouTube Data API v3 → Enable.
2. Credentials → Create credentials → API key.
3. Вставь ключ в `YOUTUBE_API_KEY` внутри `config.js`.
4. Ограничь ключ по API YouTube Data API v3 и по HTTP referrer для своего домена GitHub Pages.

## 4. Обнови GitHub Pages

В корень репозитория `sync-watch` загрузи все файлы из архива, включая новые:
- `index.html`
- `styles.css`
- `app.js`
- `config.js`
- `supabase-migration-04.sql` (можно не публиковать, он нужен только для SQL Editor)
- `icon.svg`
- `manifest.webmanifest`

После Commit changes открой сайт с жёстким обновлением Ctrl+F5.

## 5. Проверка

1. Открой SYNC в двух разных браузерах/на двух устройствах.
2. Войди двумя аккаунтами.
3. Создай комнату на первом устройстве и открой пригласительную ссылку на втором.
4. На первом устройстве выбери YouTube/RUTUBE → найди ролик → «Смотреть вместе».
5. Проверь, что второй участник получил то же видео; при блокировке autoplay нажми «Начать общий просмотр».
6. Проверь паузу и перемотку.

## Файлы

- `index.html` — разметка и PWA метаданные.
- `styles.css` — новый дизайн.
- `app.js` — Supabase Auth, друзья, комнаты, поиск/плееры и синхронизация.
- `config.js` — публичные настройки Supabase и ключ YouTube API.
- `supabase-migration-04.sql` — миграция базы данных для аватаров и состояния комнаты.
- `icon.svg` — фирменная иконка.
- `manifest.webmanifest` — параметры установки веб-приложения.
