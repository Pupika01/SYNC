# SYNC — prototype 0.2

Минималистичный интерфейс для совместного просмотра.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере или загрузите все файлы из папки на GitHub Pages / другой статический хостинг.
3. Чтобы открыть комнату на другом устройстве, нажмите «Пригласить» и отправьте полученную ссылку.

## Что есть в прототипе

- минималистичный адаптивный интерфейс для компьютера и телефона;
- комнаты с пригласительной ссылкой без кодов;
- добавление и удаление друзей в локальном списке;
- приглашение друзей в комнату ссылкой;
- чат и список участников для демонстрации;
- выбор YouTube, Rutube, VK Видео, Netflix и Кинопоиска;
- поиск YouTube внутри SYNC при добавлении ключа YouTube Data API v3;
- запуск выбранного результата YouTube во встроенном плеере.

## Как работает поиск видео

Поле ссылки убрано. Для YouTube можно включить поиск внутри приложения: создай API key в Google Cloud Console, включи YouTube Data API v3 и вставь ключ в `config.js` вместо пустой строки. Для ключа стоит установить ограничения по HTTP referrer и по API.

Пока ключ не добавлен, SYNC открывает официальный поиск YouTube. Для Rutube, VK Видео, Netflix и Кинопоиска поиск тоже открывается на официальной площадке: автоматическое получение каталога для них требует отдельных API/серверной интеграции. У Netflix и Кинопоиска защищённое воспроизведение обычно нельзя встроить в сторонний сайт, поэтому их просмотр должен оставаться на официальной площадке.

## Важные ограничения текущей версии

Это фронтенд-прототип без backend. Пригласительная ссылка задаёт идентификатор комнаты в URL, но сама по себе пока не создаёт общую сетевую комнату. Добавленные друзья сохраняются только в браузере текущего пользователя. Чат и список участников синхронизируются только между вкладками одного браузера через BroadcastChannel; между разными устройствами нужен Supabase Realtime или другой backend.

Также пока не синхронизируется Play/Pause/перемотка. Для этого понадобится интеграция с API плееров и серверный канал событий.

## Файлы

- `index.html` — структура страницы;
- `styles.css` — оформление;
- `app.js` — логика комнат, локальных друзей, поиска и плеера;
- `config.js` — необязательный ключ YouTube Data API.
