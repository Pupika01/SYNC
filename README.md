# SYNC — prototype 0.1

Статический прототип сайта для совместных просмотров.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере или загрузите три файла (`index.html`, `styles.css`, `app.js`) на GitHub Pages / любой статический хостинг.
3. Для проверки локального обмена откройте один и тот же адрес с одинаковым `?room=SYNC-4821` в нескольких вкладках одного браузера.

## Уже работает

- адаптивный тёмный интерфейс SYNC;
- выбор платформы;
- подключение YouTube через официальный embed-плеер;
- подключение публичных видео Rutube через официальный embed URL (если сервис разрешает встраивание);
- комнаты с кодом и ссылкой-приглашением;
- локальный чат и обмен событиями между вкладками одного браузера через BroadcastChannel;
- смена отображаемого имени и полноэкранный режим.

## Важно: что пока не реализовано

Это фронтенд-прототип без сервера. Код комнаты сам по себе пока не создаёт сетевую комнату между разными устройствами. Для этого нужно подключить backend (например, Supabase Realtime) и хранение комнат/сообщений.

Netflix и Кинопоиск используют защищённое воспроизведение и не предоставляют обычный iframe-плеер для произвольного стороннего сайта. В прототипе их ссылки открываются на официальной площадке в отдельной вкладке. VK Видео также пока открывается отдельно, если нет доступного официального embed-кода.

Даже для встроенных YouTube/Rutube-плееров синхронное управление воспроизведением ещё не подключено. Для следующего этапа понадобятся API конкретных плееров и серверный канал обмена событиями.
